# Практична робота — варіант 1: каталог товарів

Відкрийте `index.html` у браузері. Зовнішні ресурси не потрібні.
За замовчуванням підключено `style-scss.css`. Щоб перевірити Less,
замініть у `<link>` назву на `style-less.css`. Не підключайте обидва одночасно.

## Компіляція

Потрібен Node.js. У каталозі роботи виконайте:

```sh
npx --yes --package sass sass --no-source-map style.scss style-scss.css
npx --yes --package less lessc style.less style-less.css
```

Три картки містять назву, опис, ціну та кнопку «Купити».
У вихідних стилях є змінні, вкладеність, міксин із параметрами,
`&:hover` та медіазапит до 600 px. Колонки: 3 на широкому екрані,
2 до 1000 px та 1 до 600 px. Кнопки показують навчальне повідомлення.
Символи товарів декоративні та приховані від допоміжних технологій.
